# Диспетчер email-рассылок (n8n)

Веб-интерфейс для маркетологов и менеджеров: создание и запуск массовых
email-рассылок через workflow в n8n без прямого доступа к самой системе
автоматизации.

## Возможности

- название рассылки, тема письма
- HTML-шаблон письма с подсветкой синтаксиса и live-предпросмотром
- переменные `{{name}}`, `{{company}}`, `{{email}}` — подстановка из Excel
- загрузка контактов из `.xlsx` (drag-and-drop) с валидацией:
  - проверка обязательных колонок `email`, `name`, `company`
  - проверка формата email, построчные ошибки с номером строки
- планирование даты и времени запуска
- отправка данных в n8n через Webhook (`multipart/form-data`, `POST`)
- сводка отправки в реальном времени и блокировка кнопки запуска до готовности всех полей

## Стек

React 19, TypeScript, Tailwind CSS v4, React Hook Form, SheetJS (xlsx), PrismJS.
Backend не требуется — фронтенд обращается напрямую к Webhook n8n.

## Установка и запуск

```bash
npm install
npm run dev
```

Откроется адрес из вывода терминала (обычно `http://localhost:5173`).

### Продакшен-сборка

```bash
npm run build
npm run preview   # локальный просмотр собранной версии
```

Готовые статические файлы появятся в папке `dist/` — их можно разместить на
любом статическом хостинге (Vercel, Netlify, S3, nginx и т.д.).

## Настройка Webhook n8n

1. В n8n создайте workflow, который начинается с узла **Webhook**.
2. В узле Webhook выберите метод `POST` и формат `multipart/form-data` (или
   `Multipart Form Data` — обычно n8n определяет это автоматически по
   заголовкам запроса).
3. Скопируйте Production URL вебхука.
4. В интерфейсе откройте раздел «05. Webhook n8n» и вставьте этот URL в поле
   «URL webhook».

Поле в коде сейчас содержит placeholder
`https://YOUR_N8N_HOST/webhook/launch-campaign` — реальный вебхук пока не
подключён, его нужно указать вручную при каждом запуске или захардкодить
дефолтное значение в `src/lib/webhook.ts` (`WEBHOOK_URL_PLACEHOLDER`), если
сценарий всегда один и тот же.

## Что отправляется в n8n

Запрос `POST` с `multipart/form-data` и полями:

| Поле           | Тип    | Описание                              |
| -------------- | ------ | -------------------------------------- |
| `campaignName` | string | Название рассылки                      |
| `subject`      | string | Тема письма                            |
| `htmlTemplate` | string | HTML-код письма с переменными `{{ }}`  |
| `scheduledDate`| string | Дата и время запуска, ISO (`YYYY-MM-DDTHH:mm`) |
| `excelFile`    | file   | Загруженный `.xlsx` с контактами       |

Подстановка переменных в HTML по данным из Excel должна выполняться на
стороне n8n-сценария (например, узлом Code или Function), фронтенд передаёт
шаблон и файл как есть.

## Структура проекта

```
src/
  components/        UI-компоненты (форма, загрузчик, предпросмотр, сводка)
  lib/
    contacts.ts       парсинг и валидация Excel-файла
    webhook.ts        отправка данных на Webhook n8n
  types/
    campaign.ts        общие типы
  App.tsx             основная страница «Манифест новой рассылки»
  index.css           тема Tailwind v4 и стили компонентов
```

## Известные ограничения MVP

- Поддерживается только один лист Excel (берётся первый).
- Нет сохранения черновиков рассылки между сессиями — поля сбрасываются при
  обновлении страницы.
- Нет авторизации — интерфейс предполагается размещать во внутренней сети
  или за отдельным контуром доступа.
